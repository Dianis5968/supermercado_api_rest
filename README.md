#  Supermercado API REST

Sistema de gestión de inventario desarrollado con Django y Python.

## Descripción del Proyecto
Aplicación web para el control de productos y categorías de un supermercado, con operaciones CRUD completo y consumo de API REST.

## Tecnologías Utilizadas
- Python 3
- Django
- SQLite
- HTML5
- Bootstrap

## Funcionalidades
-  Listar productos
-  Agregar nuevos productos
-  Editar productos existentes
-  Eliminar productos
-  Gestión de categorías
-  Interfaz amigable con Bootstrap
